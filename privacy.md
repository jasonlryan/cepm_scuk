# Privacy Policy for CEPM - Creative Effectiveness Prediction Machine

Last updated: April 3, 2026

## Overview

This Privacy Policy describes how the Creative Effectiveness Prediction Machine ("CEPM", "we", "us", or "our") collects, uses, and protects information when you use our service.

## Information We Collect

CEPM processes the following data:

- **Marketing asset analysis data**: Structured analysis of marketing copy and images submitted for scoring. This includes tone, readability metrics, emotional tone assessments, and visual element descriptions.
- **Persona definitions**: Donor persona configurations including emotional triggers, communication preferences, and visual preferences.
- **Analysis results**: Effectiveness scores, recommendations, and persona insights generated by the scoring engine.
- **Request metadata**: Timestamps and basic request information for debugging and service monitoring.

## What We Do NOT Collect

- No personal information about end users or donors
- No original marketing images (only structured analysis descriptions)
- No cookies or tracking
- No financial or payment information

## OAuth Authentication

We use OAuth 2.0 for authentication purposes:

- Tokens are used solely for API access control
- Access tokens expire after 30 days
- Refresh tokens can be revoked at any time
- No user identity information is stored with tokens

## Data Usage

The data we process:

- Is used to generate effectiveness scores and recommendations
- Is stored in Google Firestore for analysis history and comparison
- Is not shared with any third parties
- Is transmitted securely via HTTPS

## Data Retention

- Analysis results are retained in Firestore for historical comparison
- Persona definitions are retained until deleted by the user
- OAuth tokens expire automatically
- Server logs are automatically deleted after 30 days

## MCP Server (Claude Integration)

When used via the MCP server with Claude:

- Communication occurs over local stdio or SSE transport
- No additional data is transmitted to third parties
- The same Firestore storage and privacy protections apply

## Third-Party Services

We use the following third-party services:

- Google Cloud Run for hosting the Flask API
- Google Cloud Firestore for data storage
- No analytics tools or tracking services

## Security

- All API communications are encrypted via HTTPS
- OAuth 2.0 authentication on all data endpoints
- Google Cloud IAM for infrastructure access control
- Cryptographically secure token generation
