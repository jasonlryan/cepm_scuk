# Privacy Policy for Number Addition API

Last updated: February 24, 2025

## Overview

This Privacy Policy describes how the Number Addition API ("we", "us", or "our") collects, uses, and protects any information when you use our service.

## Information We Collect

Our API is designed to be minimalistic and privacy-focused. We collect:

- Request timestamps
- Basic request information (for debugging)
- No personal information is stored
- No cookies are used
- No user tracking

## OAuth Authentication

We use OAuth 2.0 for authentication purposes:

- Tokens are temporary and expire after 1 hour
- No user information is stored
- Authentication is used solely for API access control

## Data Usage

The data we process:

- Is used only for the immediate calculation
- Is not stored after the response is sent
- Is not shared with any third parties
- Is transmitted securely via HTTPS

## Security

We are committed to ensuring your data's security:

- All communications are encrypted via HTTPS
- We use Google Cloud Run's security features
- We implement OAuth 2.0 for secure authentication
- We follow security best practices

## Data Retention

- We do not store any calculation data
- Logs are automatically deleted after 30 days
- OAuth tokens expire after 1 hour
- No permanent data storage

## Third-Party Services

We use the following third-party services:

- Google Cloud Run for hosting
- No other third-party services are used
- No analytics tools
- No tracking services
